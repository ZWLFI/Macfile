# Macfile 1.0.3 验证记录

验证日期：2026-11-01。环境：Apple Silicon、macOS 27.0.1、Swift 6.1.2 Command Line Tools。部署目标为 macOS 13。

## 发布内容

Macfile 1.0.3（build 4）提供原生多目录工作台，包括独立标签、五种文件视图、205 个布局预设、文件操作、工作区、书签、收集篮和任务历史。

本版完善搜索范围切换、空状态恢复、键盘焦点、双行文件名和深色选中效果，并修复工具窗口菜单误操作后台目录、书签编辑对象错位和失效重命名预览。

源码位于本仓库；Apple Silicon 应用安装包及 SHA-256 校验文件位于 [Releases](https://github.com/ZWLFI/Macfile/releases)。本机安装使用 `~/Applications/Macfile.app`，已核对版本和可执行文件一致性。

## UI 检查范围

- 五种视图、路径编辑与取消、目录切换、过期异步结果、刷新保留选择、独立标签及导航历史。
- 当前目录与递归搜索、跨分栏范围切换、清除查询、Return／Escape 返回文件区、窄窗口搜索控件。
- 图片画廊实际渲染、文件夹占位、空结果与读取失败恢复、重试后回到空目录状态。
- 双行文件名实际栅格化检查、浅深主题、双击空白与双击文件夹命中逻辑。
- 两主窗口与工具窗口菜单路由、附属对话框保护、只读文本复制／全选、主菜单和工具栏状态一致。
- 管理器单项／批量动作门槛、书签被删除或重新排序后的稳定身份编辑、非法重命名预览恢复。
- 分栏、布局撤销、205 个预设入口、32 个目录窗口、多主窗口恢复、任务状态及明细。
- 隔离文件复制、标准拖放协议与 Option 语义。未对用户原文件执行测试删除、替换或移动。

截图使用测试生成的示例资料：[浅色界面](../images/macfile-light.png)、[深色界面](../images/macfile-dark.png)。UI 测试另外生成搜索、画廊、标签、窄窗口、管理器与任务窗口截图。

## 边界与未覆盖项

- UI 检查运行真实 AppKit 控件和交互逻辑，菜单检查等待真实窗口焦点；不等同于所有操作均经过完整真实鼠标手势验收。
- 本轮未重跑两个跨卷核心用例。跨卷功能需要独立测试卷验证。
- 未做 Intel、macOS 13 实机运行、跨应用完整拖放、云盘／设备故障回归或逐格式 Quick Look 验收。
- 画廊切换期间仍有瞬时 collection flow-layout 宽度提示；最终布局与截图检查通过。标准 URL 剪贴板读取有两条 `sandbox_extension_consume failed` 系统消息，后续隔离复制与内容验证成功。运行日志并非完全无警告。
- 安装包没有 Developer ID 签名或 Apple 公证，不能将本机安装验证视作所有 Mac 的发行兼容性验收。

## 复测

```bash
# 核心测试
./scripts/test.sh

# 原生 UI 集成，使用独立状态目录与测试资料
./scripts/ui-test.sh release

# 跨卷用例，须指定独立可写测试卷
MACFILE_TEST_VOLUME=/Volumes/YourTestVolume ./scripts/test.sh
```

生成的构建、日志、会话备份和临时资料位于本机 `artifacts/`，不纳入源码仓库。仓库仅保留精选截图与不含本机私有路径的测试结果。
